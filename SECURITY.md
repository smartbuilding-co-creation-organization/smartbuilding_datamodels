# Security Policy

## Supported versions

This project is in pre-1.0 development. Security fixes are applied to the
latest revision of the `main` branch and to the latest published release when
one exists.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability or exposed secret.
Use GitHub's **Security** tab to submit a private vulnerability report to the
repository maintainers. Include reproduction steps, affected files or
versions, expected impact, and any suggested mitigation.

The maintainers will acknowledge a complete report, assess its impact, and
coordinate disclosure and remediation through the private report.
